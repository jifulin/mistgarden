# 雾光庭院 · mistgarden

> 一个基于 GitHub Pages 部署的个人导航引导页

## 简介

`mistgarden`（雾光庭院）是一个简约而精致的个人导航主页，采用暗色主题 + 毛玻璃（Glassmorphism）设计风格，支持昼夜模式切换，背景图片自动轮换，适合作为浏览器主页或个人站点的统一入口。

## 功能特性

- 🌗 **昼夜模式** — 一键切换夜间 / 白天主题，偏好自动记忆
- 🖼️ **动态背景** — 随机背景图自动轮换（6秒间隔），可随时关闭锁定当前图片
- 🎴 **毛玻璃卡片** — 大尺寸云母质感容器，内含导航、联系等模块
- 📋 **双列导航** — 8 个常用站点链接，桌面 / 移动端均保持一行两张
- 💬 **一言 widget** — 随机名言金句，点击刷新
- 🕐 **实时时钟** — 显示当前时间与日期
- ⏱️ **运行计时** — 底部页脚显示网站已运行时长
- 📱 **响应式适配** — 完美支持手机、平板、桌面端
